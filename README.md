# Color Palette & Picker Studio — Gamility Tools

A modern, high-precision, client-side digital color workspace featuring bidirectional HEX/RGB/HSL/HSV/CMYK conversions, chromatic harmony generators, WCAG 2.1 contrast ratios, shade & tint scales, and CSS variable export.

---

## 🔒 100% Client-Side Privacy Guarantee

All color space conversions, chromatic calculations, and accessibility score audits execute **strictly within your local web browser**. Your design palettes, brand colors, and project aesthetics are **never transmitted, logged, or shared** with external servers or cloud analytics.

---

## ✨ Features

- **Multi-Format Color Conversion**:
  - **HEX**: 6-digit hex code (`#3B82F6`) with auto-validation.
  - **RGB**: Red, Green, Blue decimal values (`rgb(59, 130, 246)`).
  - **HSL**: Hue, Saturation, Lightness degrees and percentages (`hsl(217, 91%, 60%)`).
  - **HSV / HSB**: Hue, Saturation, Value for graphic design suites.
  - **CMYK**: Cyan, Magenta, Yellow, Key/Black print model percentages.
- **Harmonious Palette Generator**:
  - **Analogous**: Adjacent color neighbors on the color wheel.
  - **Complementary**: High-contrast 180° complementary colors.
  - **Triadic**: 120° equilateral triadic color schemes.
  - **Split-Complementary / Tetradic**: Sophisticated rectangular harmonies.
  - **Monochromatic**: Tonal depth across a single hue.
  - **Lock Individual Swatches**: Freeze favored colors while generating new palette variations.
- **WCAG 2.1 Accessibility & Contrast Checker**:
  - Real-time contrast ratio calculator against black (`#000000`) and white (`#FFFFFF`).
  - Compliance badges for **AA Normal Text**, **AA Large Text**, **AAA Normal Text**, and **AAA Large Text**.
- **10-Step Shades & Tints Matrix**:
  - Progressive gradient scale from deep shade (darkened with black) to light tint (softened with white).
  - One-click copy for any shade or tint.
- **Developer & Designer Export Tools**:
  - Copy CSS Custom Properties (`:root { --color-1: ... }`).
  - Copy JSON / JavaScript Array of hex values.
  - Download Palette as PNG preview image.
- **Responsive Dark Design**: Tailored glassmorphism UI styled for desktop, tablet, and mobile displays.
